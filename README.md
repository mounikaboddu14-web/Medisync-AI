# Medisync-AI
MediSync AI – Project Summary
MediSync AI is a healthcare resource management platform designed to improve hospital coordination by providing visibility into resource availability and predicting possible capacity shortages.

The project uses React.js for the frontend, Node.js and Express.js for backend APIs, MongoDB for data storage, and Python Flask with a Random Forest Regressor for AI-based predictions.

Key features:
- Hospital registration and resource management.
- Search and view hospital details and available resources.
- Track beds, ICU beds, ventilators, oxygen, ambulances, blood, PPE, and medicines.
- Patient registration, login, and appointment requests.
- Hospital administrator dashboard.
- Alerts and emergency record management.
- AI-based prediction of hospital resource pressure.
Machine Learning: The model uses synthetic data to estimate resource pressure and generate a risk score from 0 to 100. The report records an MAE of 1.39 and an R² value of 0.990 on synthetic test data.

Conclusion: MediSync AI demonstrates how web technologies and machine learning can support hospital resource monitoring, improve coordination, and help identify potential resource shortages.
